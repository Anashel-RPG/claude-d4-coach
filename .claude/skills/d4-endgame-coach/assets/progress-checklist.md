# Weekly Endgame Checklist

Use as a session prompt — "what should I do this week?" The coach can present this filtered by user's stated goal and time budget.

## Currency / materials
- [ ] Cap weekly Helltide for Forgotten Souls + Aberrant Cinders
- [ ] Bank 20+ Tuning Prisms (Cube tempering rerolls)
- [ ] Bank Primordial Dust → War Plans give the best rate
- [ ] Bank Horadric Resin from Dark Citadel / weekly bosses

## Glyphs
- [ ] All core glyphs at L15 (radius unlock)
- [ ] Primary offensive glyph pushed toward L21 then L46
- [ ] Run Nightmare Dungeons at highest tier that doesn't slow XP/hr

## Gear hygiene
- [ ] Every slot has 2+ Greater Affixes? If not, mark target slots.
- [ ] Tempering exhausted on all kept gear? Replace if all manuals used and bad rolls.
- [ ] Masterworking: at least one item at MW4 / MW8 / MW12 crit on key stat?

## Boss ladder
- [ ] Have enough mats for at least 3 attempts at next uber boss
- [ ] Build's GA-target uniques identified
- [ ] Cube transmute path checked before bossing — cheaper?

## Push
- [ ] Pit tier baseline established (clear in 3-4 min)
- [ ] Logged the boss DPS check pass/fail
- [ ] Identified the single biggest upgrade target (one bucket)
