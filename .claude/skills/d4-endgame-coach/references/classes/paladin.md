# Paladin

> Season: 13 · Patch: 2.4.1 · Last refreshed: 2026-05-20 · Source: https://maxroll.gg/d4/resources/paladin-class-overview

## Core identity
Melee holy warrior built around one of four Oath specializations (Zealot, Juggernaut, Judicator, Disciple). Excels at speed, tankiness, and support while managing cooldown-gated rotations and Oath-specific resources (Fervor, Resolve, Judgement, Arbiter form).

## Damage scaling buckets
- **Multiplicative sources:** Oath keyword bonuses (Fervor stacks, Resolve trigger, Judgement explosions, Arbiter form buffs); Key Passive multipliers (Coat of Arms scales off Armor + Block Chance, Exaltation buffs Arbiter form, Judgement Day chain-reaction multiplier)
- **Additive sources:** Strength (+12.5% Skill Damage per 100 pts); active skill ranks (+10% base value per rank, up to 5 ranks per skill); passive ranks (3 ranks, linear scaling)

## Common mistakes
- Skipping cooldown reduction: each skill rank reduces cooldown by 5% — under-investing skill ranks directly hurts uptime
- Choosing more than one Ultimate Skill or Key Passive (only one of each is permitted)
- Ignoring Strength: it provides both +12.5% Skill Damage and +20 Armor per 100 points — a primary stat for both offense and defense
- Neglecting Resolve stacks on Juggernaut builds; Resolve is the core defensive/damage trigger for that Oath
- Playing fully ranged — the class is primarily melee and lacks flexibility outside that role
- Spreading passive points too thin; all passives have only 3 ranks and scale linearly, so capping key ones first is correct
- Not triggering Arbiter form on Disciple builds (Falling Star is a primary transform trigger — missing it loses the Exaltation Key Passive window)
