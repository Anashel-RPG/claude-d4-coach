# Spiritborn

> Season: 13 · Patch: 2.4.1 · Last refreshed: 2026-05-20 · Source: https://maxroll.gg/d4/resources/spiritborn-class-overview

## Core identity
Brand-new class introduced with the Vessel of Hatred expansion (Season 13, Patch 2.4.1). Channels four Spirit Guardians to deal elemental damage, spending Vigor generated by Basic Skills, and customizes its identity through the Spirit Hall mechanic.

## Damage scaling buckets
- **Multiplicative sources:** Dexterity (main stat — multiplies all damage done); Spirit Hall Primary Spirit bonus
- **Additive sources:** Passive skill ranks (three ranks each, scale linearly); Spirit Guardian elemental damage bonuses (Fire/Lightning/Physical/Poison)
- **Critical / Vulnerable / Overpower hooks:** Vital Strikes (Key Passive — synergizes with Vulnerable to enhance damage, provide healing, and restore Vigor); The Seeker Ultimate applies Vulnerable to nearby foes

## Key passives / class mechanic
| Key Passive | Buffs (state/skill) | Effect | Best for |
|---|---|---|---|
| Vital Strikes | Vulnerable state | Enhances damage, provides healing, and restores Vigor when hitting Vulnerable enemies | Vulnerable-focused builds |
| Adaptive Stances | Active Spirit / all skills | Empowers the Spiritborn based on the Spirit currently being invoked | Multi-Spirit or stance-swap builds |
| Spirit Hall (class mechanic) | All skills | At level 15: select a Primary Spirit — all skills count as that Spirit's skills and unlock a special bonus. At level 30: select a Secondary Spirit for an additional bonus. | Core identity system for every build |

## Common mistakes
- Not selecting a Primary Spirit in the Spirit Hall at level 15 — this is the single biggest power spike and enables all skill-type synergies
- Ignoring Dexterity as the main damage multiplier when itemizing
- Using a second Ultimate Skill slot — only one Ultimate can be chosen; investing points in a second is wasted
- Keeping elites outside the center overlap point of Crushing Hand — both shockwaves must converge on the target for full damage
- Neglecting Vigor generation from Basic Skills, leaving Core Skills unable to fire consistently
- Forgetting the Vessel of Hatred expansion is required — the class is unavailable without it
